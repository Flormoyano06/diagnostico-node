# Diagnóstico de Entorno Node.js

Este proyecto es un script ejecutable en consola desarrollado en Node.js que informa sobre la versión, la plataforma, los argumentos y la variable de entorno del sistema utilizando la API nativa `process`.

## Requisitos
- Node.js instalado (v18+)

## Instrucciones de Uso

1. **Ejecución estándar:**
   
   npm start
